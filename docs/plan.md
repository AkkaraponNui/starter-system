# แผนโปรเจกต์: ระบบลงทะเบียนกิจกรรม

> เอกสารนี้ผู้สอนเตรียมไว้ให้ ผู้เรียนอ่านให้เข้าใจแล้วเริ่มที่ขั้น Design ได้เลย ถ้าจะเปลี่ยนขอบเขต ให้แก้ไฟล์นี้ก่อนสั่ง Codex

## ปัญหาและเป้าหมาย

ตอนนี้การรับสมัครกิจกรรมใช้แบบฟอร์มออนไลน์ทั่วไป ผู้จัดต้องนับจำนวนคนเอง มักรับเกินที่นั่ง และผู้สมัครไม่รู้ว่าตัวเองสมัครอะไรไว้บ้าง

**เป้าหมาย:** เว็บที่ผู้ใช้ล็อกอิน ดูกิจกรรม ลงทะเบียนหรือยกเลิกเองได้ ระบบไม่รับเกินจำนวนที่นั่ง และแต่ละคนเห็นเฉพาะข้อมูลของตัวเอง

## ผู้ใช้

| กลุ่ม | ต้องการอะไร | ใช้ผ่าน |
|---|---|---|
| ผู้เข้าร่วม (นักศึกษา/บุคลากร) | ดูกิจกรรม ลงทะเบียน ยกเลิก และดูกิจกรรมของตัวเอง | เว็บไซต์ |
| ผู้จัดกิจกรรม | เพิ่มกิจกรรมและกำหนดจำนวนที่นั่ง | Supabase Table Editor (รอบนี้ยังไม่มีหน้าผู้ดูแล) |

## ขอบเขต MVP

### ทำในรอบนี้

1. สมัครสมาชิกและล็อกอินด้วยอีเมลและรหัสผ่าน และออกจากระบบ
2. ดูรายการกิจกรรมที่ยังไม่เริ่ม พร้อมจำนวนที่นั่งคงเหลือ (ไม่ต้องล็อกอิน)
3. ลงทะเบียนกิจกรรม (ต้องล็อกอิน, ห้ามซ้ำ, ห้ามเกินจำนวนที่นั่ง)
4. ยกเลิกการลงทะเบียนของตัวเอง (งานเสริม)
5. หน้า "กิจกรรมของฉัน" (งานเสริม)
6. ส่งอีเมลยืนยันเมื่อลงทะเบียนสำเร็จ (งานเสริม)

### ไม่ทำในรอบนี้

- หน้าผู้ดูแลสำหรับสร้างหรือแก้กิจกรรม (ผู้จัดใช้ Supabase Table Editor แทน)
- อีเมลเตือนก่อนวันกิจกรรม และอีเมลแบบอื่นนอกจากอีเมลยืนยันการลงทะเบียน
- ชำระเงิน
- QR check-in
- รายชื่อสำรองเมื่อที่นั่งเต็ม (waitlist)
- ล็อกอินด้วย Google หรือบัญชีอื่น

## Stack

Next.js (App Router) + Supabase (Postgres, Auth, RLS) + Vercel โดยเขียนโค้ดด้วย Codex ใน VS Code · งานเสริมส่งอีเมลใช้ Gmail SMTP

## ความเสี่ยงและข้อจำกัด

| ความเสี่ยง | แนวทาง |
|---|---|
| ข้อมูลการลงทะเบียนเป็นข้อมูลส่วนบุคคล | เปิด RLS ทุกตาราง และให้เห็นเฉพาะของตัวเอง |
| หลายคนกดลงทะเบียนพร้อมกันจนเกินที่นั่ง | ตรวจที่นั่งเต็มในฐานข้อมูล ไม่ใช่แค่ปิดปุ่มบนหน้าจอ |
| key หลุดขึ้น GitHub | เก็บใน `.env.local` ซึ่งอยู่ใน `.gitignore` และใช้ publishable key ฝั่ง browser เท่านั้น |
| App Password ของ Gmail หลุด (เข้าบัญชีได้ทั้งบัญชี) | ใช้บัญชี Gmail ที่สมัครไว้ทดลองโดยเฉพาะ เก็บใน `.env.local` และ Environment Variables ของ Vercel ใช้ในโค้ดฝั่ง server เท่านั้น ห้ามขึ้นต้นด้วย `NEXT_PUBLIC_` และลบ App Password เมื่อเลิกใช้ |
| Supabase แบบฟรีส่งอีเมลยืนยันตัวตนได้จำกัดมาก | สำหรับ workshop ให้**ปิด Confirm email** ใน Supabase → Authentication → Sign In / Providers → Email เพื่อให้สมัครแล้วใช้ได้ทันที (เมื่อใช้งานจริงต้องเปิดกลับ และตั้งค่า SMTP ของตัวเอง) |
| มีเวลาทำ 3 ชั่วโมง | ทำทีละ user story ตามลำดับ US-1 → US-6 ถ้าไม่ทันให้ deploy ส่วนที่ทำเสร็จแล้ว |

## สมมติฐานที่ปรับได้

- กิจกรรมที่เริ่มไปแล้วไม่แสดงในรายการ และลงทะเบียนหรือยกเลิกไม่ได้
- ผู้ใช้ 1 คนลงทะเบียนกิจกรรมเดียวกันได้ 1 ครั้ง
- ยกเลิกแล้วที่นั่งคืนทันที และลงทะเบียนใหม่ได้ถ้ายังมีที่ว่าง
- เวลาแสดงผลเป็นเวลาประเทศไทย (Asia/Bangkok)
